3. Comandes bàsiques

La línia de comandes permet donar ordres a l'ordinador escrivint. Obre el Símbol del sistema (CMD) i fes els passos en ordre.

Què has de fer

  1. Entra a l'Escriptori amb cd Desktop, crea una carpeta amb mkdir practica i entra-hi amb cd practica. CAPTURA
  2. Crea un fitxer amb echo hola > nota.txt i comprova que hi és amb dir. CAPTURA
  3. Fes-ne una còpia: copy nota.txt copia.txt i comprova-ho amb dir. CAPTURA
  4. Crea la carpeta mkdir arxiu i mou-hi la còpia amb move copia.txt arxiu. CAPTURA
  5. Canvia el nom del fitxer: ren nota.txt notes.txt, i el de la carpeta: ren arxiu backup. Comprova-ho amb dir. CAPTURA
  6. Entra a la carpeta amb cd backup, mira què hi ha amb dir i surt amb cd ... CAPTURA
  7. Mostra l'estructura amb tree /f. CAPTURA
  8. Esborra el fitxer amb del notes.txt i comprova-ho amb dir. CAPTURA
  9. Neteja la pantalla amb cls.
