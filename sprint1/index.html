Sprint 1 · Instal·lació i configuració inicial

Índex d'apartats d'aquest sprint

1. Virtualització

Crear una màquina virtual amb VirtualBox per poder instal·lar i executar Ubuntu sense modificar directament el sistema operatiu de l'ordinador.

Configurar la màquina virtual, seleccionar la imatge ISO d'Ubuntu i assignar els recursos necessaris, com ara la memòria RAM i l'espai del disc.

Iniciar la màquina virtual i comprovar que es pot començar la instal·lació del sistema operatiu.

↑ Tornar a l'índex

2. Instal·lació del sistema operatiu

Instal·lar Ubuntu a la màquina virtual i configurar les particions del disc segons les indicacions de la pràctica.

Revisar la distribució de l'espai del disc i les particions creades abans de continuar amb la instal·lació.

En acabar, iniciar Ubuntu i comprovar que el sistema operatiu funciona correctament.

↑ Tornar a l'índex

3. Xarxa bàsica

Consultar la configuració de xarxa de l'equip, identificar les interfícies i comprovar les adreces IP configurades.

Practicar la configuració de la xarxa, incloent-hi l'adreça IP, la màscara, la passarel·la i el servidor DNS, segons les indicacions de la pràctica.

Comprovar la connectivitat mitjançant eines i ordres bàsiques de xarxa.

↑ Tornar a l'índex

4. Comandes generals

Practicar les ordres bàsiques del terminal de Linux per gestionar directoris, fitxers, permisos i informació del sistema.

Gestió de directoris i fitxers

Consultar el directori actual i el contingut dels directoris, incloent-hi els fitxers ocults. Navegar pels directoris del sistema i consultar l'ajuda de les ordres.

Crear la carpeta practiques i les subcarpetes docs, imatges i copies. Crear i editar fitxers, consultar-ne el contingut, copiar-los, canviar-los el nom i moure'ls entre carpetes.

Rutes i organització dels fitxers

Utilitzar rutes absolutes i relatives, seleccionar fitxers amb comodins, eliminar fitxers i carpetes, guardar llistats en fitxers de text i comprimir documents.

Usuaris i informació del sistema

Consultar directoris amb permisos restringits i practicar l'accés com a administrador. Crear les carpetes de la pràctica de còpies de seguretat i guardar-hi informació del sistema, la data i els usuaris connectats.

Filtrar informació dels fitxers, fer-ne una còpia de seguretat i guardar les últimes ordres executades al terminal.

↑ Tornar a l'índex

5. Instal·lació d'aplicacions

Practicar la instal·lació, la comprovació i la desinstal·lació d'aplicacions a Ubuntu mitjançant gestors de paquets.

Consultar la versió del sistema operatiu, cercar paquets i instal·lar i desinstal·lar els programes indicats a la pràctica.

Utilitzar eines com APT, DPKG i Aptitude per gestionar aplicacions i comprovar l'estat dels paquets instal·lats.
