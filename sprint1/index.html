Sprint 1 · Instal·lació i configuració inicial

Desenvolupament d'Aplicacions Multiplataforma

0483 – Sistemes Informàtics

Portada Índex de sprints Windows

1. Virtualització i instal·lació del sistema operatiu

  1. Crear una màquina virtual amb la memòria RAM i el disc assignats.
  2. Comprovar la configuració de xarxa de la màquina virtual.
  3. Carregar la imatge ISO i iniciar la instal·lació del sistema operatiu.
  4. Crear les particions del disc durant la instal·lació.
  5. Comprovar que el sistema s'inicia correctament.

2. Configuració del sistema operatiu

  1. Consultar la informació bàsica del sistema operatiu instal·lat.
  2. Identificar els components principals i les seves funcions.
  3. Revisar la configuració del sistema i les opcions disponibles.
  4. Comprovar les opcions d'actualització i recuperació del sistema.

3. Gestió de particions i emmagatzematge

  1. Consultar les particions i les unitats disponibles.
  2. Identificar l'espai assignat al sistema operatiu i l'espai lliure.
  3. Crear o configurar particions segons les indicacions de la pràctica.
  4. Comprovar que les unitats creades apareixen correctament al sistema.

4. Comandes generals de Linux

  1. Consultar el directori actual i llistar-ne el contingut, incloent-hi els fitxers ocults i els detalls dels fitxers.
  2. Navegar pels directoris del sistema, consultar el manual de les comandes i trobar opcions útils.
  3. Crear la carpeta practiques i, a dins, les carpetes docs, imatges i copies.
  4. Crear fitxers de text i d'imatge, editar-ne el contingut i consultar-lo.
  5. Copiar, canviar el nom i moure fitxers entre carpetes, utilitzant comodins per seleccionar diversos fitxers.
  6. Treballar amb rutes absolutes i relatives per localitzar directoris.
  7. Eliminar fitxers i carpetes, guardar llistats en fitxers de text i comprimir documents.
  8. Consultar directoris amb permisos restringits i practicar el canvi entre l'usuari normal i l'administrador.
  9. Crear les carpetes repte, dades i backup, i guardar-hi informació del sistema, la data i els usuaris connectats.
  10. Filtrar informació d'un fitxer, fer-ne una còpia de seguretat i guardar les últimes comandes de l'historial.

5. Configuració i comprovació de la xarxa

  1. Consultar la configuració de xarxa de l'equip i comprovar la connexió amb una adreça web i una adreça IP.
  2. Desconnectar temporalment l'adaptador de xarxa de la màquina virtual i comprovar què passa amb la connexió.
  3. Tornar a connectar l'adaptador i canviar-ne el mode de connexió per comparar els resultats.
  4. Modificar temporalment la configuració DNS, comprovar la connexió i després restaurar la configuració automàtica.
