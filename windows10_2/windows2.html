2. Llicències

Windows necessita una llicència per utilitzar-se legalment. Hi ha llicències Retail, OEM i de volum. Als servidors, a més, hi ha les CAL.

Què has de fer

  1. Ves a Configuració → Sistema → Activació i anota l'edició de Windows i si està activat. CAPTURA
  2. Al CMD, executa slmgr /xpr (estat de l'activació) i slmgr /dli (tipus de llicència). CAPTURA
  3. Busca el preu de Windows 11 Home i Pro a la botiga oficial de Microsoft i a una altra botiga. CAPTURA
  4. Busca què és una CAL (Client Access License) a la web de Microsoft. CAPTURA
