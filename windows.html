1. Màquina virtual, instal·lació i particions

Una màquina virtual és un ordinador simulat que funciona dins del teu. Hi instal·laràs Windows a partir d'una imatge ISO i repartiràs el disc en particions.

Què has de fer

  1. Crea a VirtualBox una màquina anomenada Windows-NomCognom amb 4 GB de RAM i un disc de 50 GB. CAPTURA
  2. A Configuració → Xarxa, comprova que l'Adaptador 1 està habilitat i en mode NAT. CAPTURA
  3. Carrega la ISO de Windows 10 i comença la instal·lació (idioma, usuari amb el teu nom i contrasenya).
  4. A la pantalla de particions, crea una partició de 30 GB per a Windows i deixa els altres 20 GB sense assignar. CAPTURA
  5. Quan arrenqui Windows, obre diskmgmt.msc i amb l'espai lliure crea una partició NTFS amb la lletra D: i el nom DADES. CAPTURA

Atenció: no facis servir tot el disc per a Windows. Deixa els 20 GB lliures per poder crear la partició DADES. Windows també crearà unes particions petites per al sistema; és normal.

2. Llicències

Windows necessita una llicència per utilitzar-se legalment. Hi ha llicències Retail, OEM i de volum. Als servidors, a més, hi ha les CAL.

Què has de fer

  1. Ves a Configuració → Sistema → Activació i anota l'edició de Windows i si està activat. CAPTURA
  2. Al CMD, executa slmgr /xpr (estat de l'activació) i slmgr /dli (tipus de llicència). CAPTURA
  3. Busca el preu de Windows 11 Home i Pro a la botiga oficial de Microsoft i a una altra botiga. CAPTURA
  4. Busca què és una CAL (Client Access License) a la web de Microsoft. CAPTURA
↑ Tornar a l'índex

3. Comandes bàsiques

La línia de comandes permet donar ordres a l'ordinador escrivint. Obre el Símbol del sistema (CMD) i fes els passos en ordre.

Què has de fer

  1. Entra a l'Escriptori amb cd Desktop, crea una carpeta amb mkdir practica i entra-hi amb cd practica. CAPTURA
  2. Crea un fitxer amb echo hola > nota.txt i comprova que hi és amb dir. CAPTURA
  3. Fes-ne una còpia: copy nota.txt copia.txt i comprova-ho amb dir. CAPTURA
  4. Crea la carpeta mkdir arxiu i mou-hi la còpia amb move copia.txt arxiu. CAPTURA
  5. Canvia el nom del fitxer: ren nota.txt notes.txt, i el de la carpeta: ren arxiu backup. Comprova-ho amb dir. CAPTURA
  6. Entra a la carpeta amb cd backup, mira què hi ha amb dir i surt amb cd ... CAPTURA
  7. Mostra l'estructura amb tree /f. CAPTURA
  8. Esborra el fitxer amb del notes.txt i comprova-ho amb dir. CAPTURA
  9. Neteja la pantalla amb cls.

4. Aplicacions i punts de restauració

Un punt de restauració guarda l'estat del sistema en un moment concret. Serveix per tornar a una configuració anterior si apareix algun problema.

Què has de fer

  1. Busca «Crear un punt de restauració», activa la protecció del sistema al disc C: i crea un punt anomenat Abans de Chrome. CAPTURA
  2. Descarrega Chrome de la web oficial de Google, instal·la'l i obre'l. CAPTURA
  3. Ves a Restaurar sistema, tria el punt creat i prem «Cerca programes afectats»: hi ha d'aparèixer Chrome. CAPTURA
  4. Restaura el sistema i comprova que Chrome ja no hi és. CAPTURA
↑ Tornar a l'índex

5. Xarxa

Per tenir Internet, l'equip necessita una adreça IP, una connexió activa i un servidor DNS. Amb les comandes ping pots comprovar la connexió i detectar problemes.

Què has de fer

  1. Amb l'adaptador en mode NAT, executa ipconfig, ping google.com i ping 8.8.8.8. CAPTURA
  2. A VirtualBox, ves a Dispositius → Xarxa, desmarca «Connecta el cable» i repeteix els dos ping. CAPTURA
  3. Torna a connectar el cable i canvia l'adaptador a Adaptador pont. Repeteix ipconfig i els dos ping. CAPTURA
  4. A Windows, posa el DNS manual 1.2.3.4 i repeteix els dos ping. Després torna a posar el DNS en automàtic. CAPTURA
