5. Xarxa

Per tenir Internet, l'equip necessita una adreça IP, una connexió activa i un servidor DNS. Amb les comandes ping pots comprovar la connexió i detectar problemes.

Què has de fer

  1. Amb l'adaptador en mode NAT, executa ipconfig, ping google.com i ping 8.8.8.8. CAPTURA
  2. A VirtualBox, ves a Dispositius → Xarxa, desmarca «Connecta el cable» i repeteix els dos ping. CAPTURA
  3. Torna a connectar el cable i canvia l'adaptador a Adaptador pont. Repeteix ipconfig i els dos ping. CAPTURA
  4. A Windows, posa el DNS manual 1.2.3.4 i repeteix els dos ping. Després torna a posar el DNS en automàtic. CAPTURA
